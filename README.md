# nbaStatPredictor
This is a nba stat predictor that uses player data to determine whether certain over/under predictions are worth betting on
For this project I will be using React for the front end, as of now im only working on pulling 3 stats, Points Rebounds and Assists
Once a user enters the name of a player I will use NBAApi to pull those three stats from the player, then using python to actually do the calculations in order to determine the liklehood of averages. For my next feature i plan on letting users input lines and using LSRL to detemine how impactful each line is on the player averages so that users can make better decisions when they gamble (ironic)
